## Chatbot Using ChatterBot

**Intern ID:** CITS9489

### Project Description
HariniBot is a simple conversational chatbot developed using Python and the ChatterBot library. It is trained with basic conversations and responds to user messages.

### Technologies Used
- Python 3.11
- ChatterBot
- spaCy
- SQLite

### Features
- Responds to basic greetings
- Answers simple questions
- Uses ChatterBot for conversational responses
- Supports exiting the conversation using `exit`

### Installation
Install the required library:

```bash
py -3.11 -m pip install chatterbot
```

Install the English language model:

```bash
py -3.11 -m spacy download en_core_web_sm
```

### How to Run
From the `Cod-Tech Developers` folder, run:

```bash
py -3.11 chatbot-using-chatterbot/chatbot.py
```
